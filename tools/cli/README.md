# @psp/cli

## Propósito
Comandos operativos: catalog (imprime capacidades), seed (dataset demo), bundle (bundle efectivo de una máquina con procedencia), simulate-fleet (N agentes virtuales), demo (arranque guiado).

## Cómo se usa
Pendiente de completar por el paquete.

## Cómo se prueba
```bash
pnpm --filter @psp/cli test
```
