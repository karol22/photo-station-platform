# @psp/station-agent

## Propósito
Lo que vive dentro de cada máquina: identidad, bundle activo y caché de activos, sesiones con almacén efímero de fotos y retención, outbox/inbox idempotentes, heartbeat y comandos, impresoras y terminal de pago mock, simulación de releases, panel técnico, modo standalone sin nube.

## Cómo se usa
Pendiente de completar por el paquete.

## Cómo se prueba
```bash
pnpm --filter @psp/station-agent test
```
