# Estilos por pantalla

Un archivo por pantalla. Existe para que varias personas puedan trabajar en pantallas distintas a
la vez sin editar todas el mismo archivo.

`../styles.css` los importa y guarda sólo lo común: el marco, las cinco bandas y las piezas que
comparten todas las pantallas. Cada archivo de aquí sólo toca clases con su propio prefijo.
