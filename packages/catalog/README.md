# @psp/catalog

## Propósito
Catálogo de capacidades: cada paquete exporta CATALOG (CatalogEntry[]); este paquete las agrega con las entradas de apps, protocolos, comandos CLI y compuertas. pnpm catalog lo imprime.

## Cómo se usa
Pendiente de completar por el paquete.

## Cómo se prueba
```bash
pnpm --filter @psp/catalog test
```
