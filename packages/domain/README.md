# @psp/domain

## Propósito
Lógica pura de negocio sin I/O: jerarquía y contención de alcance, RBAC, resolución de precios y promociones, gating por capacidades, resolución de features y entitlements, máquinas de estado de sesión y pago, políticas de retención, selección de rollout.

## Cómo se usa
Pendiente de completar por el paquete.

## Cómo se prueba
```bash
pnpm --filter @psp/domain test
```
