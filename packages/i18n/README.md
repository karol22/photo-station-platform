# @psp/i18n

## Propósito
Localización: catálogos de mensajes es/en con paridad de claves verificada por compuerta, función t(), formateo de dinero en unidades menores, fechas y horas por zona.

## Cómo se usa
Pendiente de completar por el paquete.

## Cómo se prueba
```bash
pnpm --filter @psp/i18n test
```
