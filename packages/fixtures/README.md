# @psp/fixtures

## Propósito
Dataset demo: dos organizaciones ficticias, franquicias, regiones, ubicaciones, máquinas con perfiles de hardware distintos, productos, precios, presets documentales, plantillas, experiencias, campañas, activos generados, usuarios y roles. Ids fijos; generador de flota para N máquinas.

## Cómo se usa
Pendiente de completar por el paquete.

## Cómo se prueba
```bash
pnpm --filter @psp/fixtures test
```
