# @psp/ui

## Propósito
Design system compartido: tokens (color, espacio, tipografía, radios), tema por bundle de branding, componentes de kiosco (botones grandes, tarjetas, cuenta regresiva, barra de progreso, diálogos) y de admin (tablas, filtros, formularios, badges de estado, procedencia de configuración).

## Cómo se usa
Pendiente de completar por el paquete.

## Cómo se prueba
```bash
pnpm --filter @psp/ui test
```
